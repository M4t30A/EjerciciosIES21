# 💻 pryAmayaInterfazGrafica

Repositorio que reúne las soluciones a los trabajos prácticos y guías de ejercicios desarrollados en **C# (.NET Framework)** para la materia **Introducción a la Programación** en **IES 21**. 

El proyecto abarca tanto aplicaciones de consola como interfaces gráficas en **Windows Forms**, con foco en la lógica de programación, manejo de eventos y diseño de interfaz.

---

# 🛠️ Tecnologías y Herramientas

* **Lenguaje:** C#
* **Entorno de Desarrollo (IDE):** Microsoft Visual Studio 2022
* **Tecnología de GUI:** .NET Windows Forms

### Convención de Controles

* `btn...` → Botones (`Button`)
* `txt...` → Cajas de Texto (`TextBox`)
* `lbl...` → Etiquetas (`Label`)

---

# 🚀 Cómo ejecutar el proyecto localmente

### 1. Clonar el repositorio

```bash
git clone https://github.com/M4t30A/pryAmayaInterfazGrafica.git
```

### 2. Abrir la solución

1. Navega hasta la carpeta `pryAmayaEjerciciosIES21`.
2. Abre el archivo con extensión `.sln` en **Visual Studio 2022**.

### 3. Compilar y ejecutar

1. Selecciona el proyecto o formulario que deseas probar como **proyecto de inicio**.
2. Presiona **F5** o haz clic en el botón **Iniciar** en Visual Studio.
